# Dow DE Replay Analyzer

**Анализатор реплеев Dawn of War: Definitive Edition**  
Извлекает полную информацию о матче: игроков, расы, карту, длительность и **все действия** игроков, превращая числовые идентификаторы (actionId) в читаемые названия.

## ✨ Особенности

- ✅ Парсинг метаданных (игроки, расы, карта, продолжительность)
- ✅ Извлечение всех игровых команд (3500+ за матч)
- ✅ Автоматическая фильтрация служебных пакетов синхронизации (SYNC)
- ✅ Интерактивное обучение – программа запрашивает описание для новых actionId и сохраняет их в локальную базу
- ✅ Поддержка всех фракций DoW: Definitive Edition

## 🚀 Быстрый старт

### Требования

- [Java 17](https://adoptium.net/) или новее
- Git (для клонирования)

### Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Ravenz16/dow-de-replay-parser.git
   cd dow-de-replay-parser
Скомпилируйте проект

bash
javac com/dow/replay/parser/*.java
Запустите анализ на вашем реплее

bash
java com.dow.replay.parser.Main "C:\Путь\к\реплею.rec"
Первый запуск
При первом анализе реплея программа обнаружит неизвестные actionId и запросит их описание:

text
Обнаружены новые actionId. Введите для них описания (Enter чтобы пропустить):
ID 16974083: Постройка: Генератор (Тау)
ID 33620481: Постройка: Оружейная (Космодесант)
Введённые описания сохранятся в файл action_ids.properties и будут использоваться в следующих запусках автоматически.

🗺️ План развития
LZSS-распаковка – первые три больших блока в реплее сжаты LZSS. Их распаковка даст доступ ко всем командам (сейчас используется только последний блок).

Автоматический словарь actionId – парсинг игровых файлов W40kData.sga для автоматического извлечения названий зданий, юнитов и способностей.

Определение победителя – поиск событий победы/поражения (VICTORY/DEFEAT).

Экспорт в JSON/CSV – для дальнейшего анализа в таблицах или визуализации.

Поддержка других версий DoW (Soulstorm, Dark Crusade).
